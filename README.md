# Student Task Manager

A small JavaScript project demonstrating Git version control, automated tests with Jest, and CI with GitHub Actions.

## Features
- Create tasks with validated titles
- Add, complete, remove, and filter tasks
- Unit tests for normal and error cases
- GitHub Actions test workflow

## Requirements
Node.js 20+ and npm.

## Run
```bash
npm install
npm test
```

## Structure
- `src/taskManager.js` — task functions
- `tests/taskManager.test.js` — Jest tests
- `.github/workflows/tests.yml` — CI workflow
